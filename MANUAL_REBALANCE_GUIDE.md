## 🚨 TROUBLESHOOTING

### **"I didn't get an approval email"**
- Check spam folder
- Wait 1-2 minutes (sometimes delayed)
- Check Coinbase notifications in-app
- Go to Coinbase → Settings → Security → Recent Activity

### **"XRP not arriving on Gemini"**
- Usually takes 4-30 seconds
- Can take up to 5 minutes if network is busy
- Check transaction status on Coinbase
- Check Gemini deposit history

### **"I approved but transfer still pending"**
- First-time transfers can take 5-10 minutes
- Coinbase does extra security checks
- Be patient, it will arrive!

### **"I don't see XRP option on Gemini"**
- Make sure you're on "Deposit" not "Withdraw"
- Make sure you selected "Crypto" tab
- Search for "XRP" in the search box
