## 🚀 HOW TO DEPLOY FROM GITHUB

### **Option 1: Deploy to Railway** (Recommended)

**Step 1: Create Railway Project** (2 min)
1. Go to https://railway.app
2. Sign in with GitHub
3. Click "New Project"
4. Select "Deploy from GitHub repo"
5. Choose "Muckmuckmuckmuck/ArbitrageBot"

**Step 2: Configure Environment** (5 min)
1. Go to project → Variables
2. Click "Add Variable"
3. Add all from `.env.railway`:
   ```
   PIONEX_API_KEY=your_key
   PIONEX_SECRET_KEY=your_secret
   PIONEX_TESTNET=false
   COINBASE_API_KEY=your_key
   COINBASE_SECRET_KEY=your_secret
   COINBASE_PASSPHRASE=your_passphrase
   COINBASE_SANDBOX=false
   LOG_LEVEL=INFO
   ```

**Step 3: Deploy** (automatic)
1. Railway detects Procfile
2. Installs from requirements.txt
3. Starts bot automatically
4. Check logs: Look for "READY FOR CROSS-EXCHANGE ARBITRAGE"

**Step 4: Monitor**
1. Railway dashboard → Logs
2. Watch for successful cycles
3. Verify transfers complete
4. Check profits accumulating

**Total time**: 10-15 minutes ✅
